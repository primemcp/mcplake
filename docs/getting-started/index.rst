Getting Started
===============

Three ways in, depending on how much you want to set up yourself:

:doc:`quickstart`
   Run the demo stack and watch the gateway allow one user, refuse another,
   and redact a response — about five minutes, needs only Docker or Podman.

:doc:`installation`
   Build the gateway binary (and optionally the admin web UI) from source.

:doc:`first-gateway`
   Put the gateway in front of an MCP server with your own OIDC provider:
   a minimal configuration, one access policy, one filter, and how to test
   them.

:doc:`demo`
   The full tour of the demo stack: every service, the admin UI, the MCP
   control server, and how to reset it.
